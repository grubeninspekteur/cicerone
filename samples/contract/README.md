# Sample contract

A short services agreement with the kind of defects that creep into drafts, for trying Cicerone on legal text.
It is an invented example for demonstrating the editor and not a template to use.

Run **Cicerone: Set Up This Workspace For…** and choose *Contracts and legal drafting*. With the mock gateway you can
then open the context menu in `services-agreement.md` and choose *Check Defined Terms*.
