# The Salt Ledger — sample manuscript

A few pages of a novel in progress, for trying Cicerone on prose. Run **Cicerone: Set Up This Workspace For…**
and choose *Fiction manuscript*. With the mock gateway you can then select the second paragraph of chapter 1 and
choose *Tighten This Passage* from the context menu, or ask: "Keep a timeline of the story for me."

Loose ends are marked `[[like this]]`. There is one continuity slip between chapters 1 and 3.
